# 🛍️ Shoppix

Shoppix is a full-stack e-commerce web application built using the **MERN Stack**. It provides a complete online shopping experience where users can browse products, manage their cart, place orders, make online payments, and receive order confirmation emails.

The application also includes an **Admin Dashboard** for managing products and orders.

---

## 🚀 Features

### 👤 User

- User registration and login
- resgisteration confirmation message
- JWT-based authentication
- Browse products
- View product details
- Add products to cart
- Update cart quantity
- Remove products from cart
- Manage shipping address
- Place orders
- View order history
- Online payment using Razorpay
- Logout functionality

### 🛠️ Admin

- Admin authentication
- Add new products
- Update products
- Delete products
- Upload product images
- View all orders
- Manage customer orders
- Update order status
- Separate admin dashboard
